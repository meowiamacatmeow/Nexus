Settings

Live Claude (online — preview only)
About online mode.
Live Claude calls the real Anthropic API and only works while you're testing NEXUS here, inside Claude's own chat preview — the platform wires that one call through automatically. Once this page is published as a standalone link, or built as the native Android app, that network path is gone: a published page's sandboxing blocks all outbound requests (not just this one), and the native app will need its own HTTP client and a real provider-abstraction layer, exactly as the original spec's Section 6 describes — interchangeable providers, online providers only when the user explicitly configures one (e.g. supplies their own API key in Settings on-device, never hardcoded). That part is genuinely 1.0 work, not something a browser page can shortcut.
Privacy
No network requests are made. No API keys are requested. Chat data remains in memory until you export it.
Build architecture
UI, state, data schema, validation, demo provider, policy engine and audit log are separated into individual JavaScript modules. The prototype still runs without a backend.

NEXUS 0.6 adds specialized agents: five scoped personas (Developer, System, Security, Data, Research) from the original spec's agent table, each restricted to specific policy categories. Switch the active agent per conversation from the selector above the composer — a request outside that agent's scope is declined with a pointer to the right agent, rather than silently executing anyway. A Live Claude provider is also available in Settings: it calls the real Anthropic API, but only works inside Claude's own chat preview — publishing this page or building the native app removes that network path entirely, by design of each environment's sandboxing. Builds on 0.5's Environments view, 0.4's Files view and dialog fixes, 0.3's execution engine, 0.2's local autosave and 0.1.3's policy engine, permissions and audit log.
